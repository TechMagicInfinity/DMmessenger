FNLink

FNLink («Микро-мессенджер») — небольшой десктопный мессенджер со сквозным шифрованием. Приложение написано на Electron (JavaScript), сообщения шифруются на устройстве отправителя, а сервер хранит и передаёт только шифротекст.

Возможности
Сквозное шифрование переписки (ECDH P-256 + HKDF + AES-256-GCM, Web Crypto API)
Поиск людей по @нику и заявки в друзья
Профили с аватаром
Автообновление через GitHub Releases
Версии для Windows и Linux
Установка

Все сборки лежат на странице релизов: https://github.com/TechMagicInfinity/FNLink/releases Скачивайте файлы из самого свежего релиза (раздел Assets).

Windows
Скачайте установщик .exe из последнего релиза.
Запустите его. Приложение установится для вашего пользователя (права администратора не нужны) и добавит ярлыки в меню «Пуск» и на рабочий стол.
Если Windows показывает окно «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Установщик пока не подписан сертификатом, поэтому система не знает издателя.
Запустите FNLink из меню «Пуск».

Удаление: «Параметры → Приложения → Установленные приложения → FNLink → Удалить».

Linux

Подходит любой дистрибутив с поддержкой AppImage (проверялось на Ubuntu).

Скачайте файл FNLink-<версия>.AppImage из последнего релиза.
Сделайте его исполняемым и запустите:
bash
   chmod +x FNLink-*.AppImage
   ./FNLink-*.AppImage

Можно также нажать на файл правой кнопкой → «Свойства» → «Разрешить выполнение файла как программы» и открыть двойным кликом. 3. При первом запуске приложение само:

копирует себя в ~/.local/share/fnlink/FNLink.AppImage (скрытая папка, исходный файл остаётся нетронутым);
создаёт ярлык и иконку, после чего FNLink находится через поиск (клавиша Super).
После этого скачанный файл можно удалить, а приложение запускать из меню. Чтобы закрепить его на панели, нажмите правой кнопкой по значку и выберите «Добавить в избранное».

Отключить автоматическую установку и создание ярлыка можно, запустив с переменной окружения:

bash
FNLINK_NO_INSTALL=1 ./FNLink-*.AppImage

Если AppImage не запускается с ошибкой про FUSE (бывает на Ubuntu 22.04 и новее):

bash
sudo apt install libfuse2        # на Ubuntu 24.04: sudo apt install libfuse2t64

Удаление:

bash
rm -rf ~/.local/share/fnlink ~/.config/fnlink
rm -f ~/.local/share/applications/fnlink.desktop ~/.local/share/icons/fnlink.png

Папка ~/.config/fnlink содержит ваш аккаунт и ключ шифрования (см. ниже), поэтому после её удаления прежняя переписка станет недоступна.

Обновления

Приложение само проверяет наличие новой версии при запуске, скачивает её в фоне и устанавливает при следующем закрытии. Версия приложения указана в заголовке окна (например, «Микро-мессенджер v1.2.7»).

Запуск из исходников

Нужен Node.js (LTS).

bash
git clone https://github.com/TechMagicInfinity/FNLink.git
cd FNLink
npm install
npm start
Безопасность и ограничения
Приватный ключ создаётся и хранится только на вашем устройстве. Если удалить данные приложения (~/.config/fnlink на Linux, %APPDATA%\fnlink на Windows), прежняя переписка не восстановится.
Сервер видит метаданные (кто с кем общается и когда), но не содержимое сообщений.
Публичные ключи собеседников раздаёт сервер, а встроенной проверки отпечатков пока нет.
Ротации ключей (forward secrecy) нет: утечка приватного ключа раскрывает всю историю этого устройства.
Проект учебный/любительский и не проходил независимый аудит. Не используйте его там, где от безопасности зависит многое.
